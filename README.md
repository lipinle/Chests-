# Iron Chests: Rewritten (NeoForge 1.20.1)

A from-scratch rewrite of the classic **Iron Chests** idea for **Minecraft 1.20.1 / NeoForge 47.1.x**.
มอดหีบเหล็กเขียนใหม่ทั้งหมดสำหรับ Minecraft PC 1.20.1 (NeoForge)

## Chests / หีบ

| Chest | Slots | Layout | Notes |
|---|---|---|---|
| Copper Chest | 45 | 9 x 5 | |
| Iron Chest | 54 | 9 x 6 | |
| Gold Chest | 81 | 9 x 9 | |
| Diamond Chest | 108 | 12 x 9 | |
| Crystal Chest | 108 | 12 x 9 | See-through, shows its biggest stacks spinning inside |
| Obsidian Chest | 108 | 12 x 9 | Blast resistant |
| DirtChest 9000! | 1 | 1 x 1 | Joke chest |

All chests: lid animation + sounds, comparator output, hopper support, waterloggable, keep custom names when broken.

## Upgrades / ชุดอัปเกรด

Sneak + right-click a chest with an upgrade kit to upgrade it **in place** – items and name are kept.
(ย่อตัว + คลิกขวาที่หีบ ของข้างในไม่หาย)

`Wood → Copper`, `Wood → Iron`, `Copper → Iron`, `Iron → Gold`, `Gold → Diamond`, `Diamond → Crystal`, `Diamond → Obsidian`

## Recipes / สูตร

- Copper Chest: 8 copper ingots around a wooden chest
- Iron Chest: 8 iron ingots around a wooden chest, or `IGI / GCG / IGI` (iron, glass, copper chest)
- Gold Chest: 8 gold ingots around an iron chest
- Diamond Chest: `GGG / DCD / GGG` (glass, diamond, gold chest)
- Crystal Chest: 8 glass around a diamond chest
- Obsidian Chest: 8 obsidian around a diamond chest
- Dirt Chest: 8 dirt around a wooden chest
- Upgrade kits: same materials as the chest, with planks / ingots in the middle (see JEI or `data/ironchests/recipes`)

## Building / วิธีบิลด์

Requires JDK 17.

```
./gradlew build
```

The mod jar ends up in `build/libs/`. Every push is also built by GitHub Actions
(tab **Actions → Build → Artifacts → `ironchests-mod`**).

Put the jar into `.minecraft/mods` of a NeoForge 1.20.1 (47.1.x) install.

Run a dev client with `./gradlew runClient`.

## Resources

Textures, models, recipes, loot tables and translations (English + ไทย) are generated by
`python3 tools/generate_resources.py` (needs Pillow). Edit the script and re-run it to change them.
