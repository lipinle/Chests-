# Storage Plus — Add-on Minecraft Bedrock (มือถือ / PE)

Add-on นี้เพิ่ม **หีบใหญ่ 4 ระดับ** (เหล็ก ทอง เพชร เนเธอไรต์) กับ **ลิ้นชัก (Drawer)** ที่เก็บของได้ไม่กี่ชนิด แต่เก็บได้ชนิดละมาก ๆ เกินลิมิต 64 ต่อสแต็ก และอัปเกรดให้เก็บได้มากขึ้นอีก

ต้องใช้ Minecraft Bedrock **1.21.90 ขึ้นไป** (สคริปต์ใช้ `@minecraft/server` 2.0.0)

## วิธีติดตั้ง (มือถือ)

1. ดาวน์โหลด `dist/StoragePlus.mcaddon` (สร้างเองได้ด้วย `python3 tools/build.py`)
2. กดเปิดไฟล์ แล้วเลือกเปิดด้วย Minecraft เกมจะ import ให้ทั้ง 2 แพ็ก
3. สร้างโลกใหม่หรือแก้โลกเดิม แล้วไปที่ **Behavior Packs** และเปิด *Storage Plus BP* (Resource Pack จะเปิดตามให้เอง)

> ถ้ามือถือเปิดไฟล์ .mcaddon ไม่ได้ ให้ใช้ไฟล์ `StoragePlus_BP.mcpack` กับ `StoragePlus_RP.mcpack` แทน

## 1) หีบใหญ่ (Big Chests)

| หีบ | จำนวนหน้า | ช่องทั้งหมด | สูตรคราฟต์ |
|---|---|---|---|
| หีบเหล็ก | 2 | 54 (เท่าหีบคู่) | เหล็ก 8 ล้อมหีบธรรมดา |
| หีบทอง | 3 | 81 | ทอง 8 ล้อมหีบเหล็ก |
| หีบเพชร | 5 | 135 | เพชร 8 ล้อมหีบทอง |
| หีบเนเธอไรต์ | 8 | 216 | หีบเพชร + แท่งเนเธอไรต์ (ไม่ต้องเรียง) |

**วิธีใช้**
- **วาง:** ถือหีบแล้วแตะพื้นหรือบล็อก
- **เปิด:** แตะหีบ หรือกดปุ่ม *Open/เปิด* ที่ขึ้นมา
- **เปลี่ยนหน้า:** **ตี** หีบ = หน้าถัดไป, **ย่อแล้วตี** = ย้อนหน้า (บน PC ย่อแล้วคลิกขวาก็ได้)
  ชื่อหีบจะบอกเลขหน้า เช่น `Diamond Chest 2/5` และเวลามองหีบจะมีข้อความบอกบนจอ
- **เก็บหีบ:** ตีด้วย **อีเต้อ (pickaxe) 3 ครั้ง** (โหมดสร้างสรรค์ตีครั้งเดียว) ของทุกหน้าจะหล่นออกมาพร้อมตัวหีบ
- หีบทนระเบิดและไฟ มอนตีไม่พัง ลูกสูบดันไม่ได้

ของทุกชิ้นเก็บไว้ครบทุกอย่าง ทั้งเอนชานต์ ชื่อ และของที่อยู่ในกล่องชัลเกอร์

## 2) ลิ้นชัก (Drawers)

ลิ้นชักแต่ละช่องเก็บของได้แค่ **1 ชนิด** แต่เก็บได้หลายพันถึงหลายแสนชิ้น

| ลิ้นชัก | ชนิดของ | สูตรคราฟต์ (P = ไม้แผ่นชนิดไหนก็ได้, C = หีบ) | ได้ |
|---|---|---|---|
| ลิ้นชัก 1 ช่อง | 1 | `PPP / PCP / PPP` | 1 |
| ลิ้นชัก 2 ช่อง | 2 (บน/ล่าง) | `PCP / PPP / PCP` | 2 |
| ลิ้นชัก 4 ช่อง | 4 (แบ่ง 4 ส่วน) | `CPC / PPP / CPC` | 4 |

### ความจุต่อช่อง (นับเป็นจำนวนชิ้น ของที่ซ้อนได้ 64)

| อัปเกรด | ตัวคูณ | 1 ช่อง | 2 ช่อง (ต่อช่อง) | 4 ช่อง (ต่อช่อง) |
|---|---|---|---|---|
| ไม่มี | x1 | 2,048 (32 สแต็ก) | 1,024 | 512 |
| เหล็ก | x4 | 8,192 | 4,096 | 2,048 |
| ทอง | x16 | 32,768 | 16,384 | 8,192 |
| เพชร | x64 | 131,072 | 65,536 | 32,768 |
| เนเธอไรต์ | x256 | **524,288** | 262,144 | 131,072 |

ของที่ซ้อนได้ 16 อย่างไข่ หรือเอนเดอร์เพิร์ล จะเก็บได้เป็นสแต็กเท่าตารางนี้ แต่จำนวนชิ้นจะน้อยกว่า (สแต็กละ 16 ชิ้น)

### สูตรอัปเกรด (S = ไม้)

| อัปเกรด | สูตร |
|---|---|
| เหล็ก | `S I S / I S I / S I S` (I = แท่งเหล็ก) |
| ทอง | `S G S / G S G / S G S` (G = แท่งทอง) |
| เพชร | `S D S / D S D / S D S` (D = เพชร) |
| เนเธอไรต์ | `S D S / D N D / S D S` (N = แท่งเนเธอไรต์) |

ถืออัปเกรดแล้วแตะลิ้นชักเพื่อใส่ ขอบหน้าลิ้นชักจะเปลี่ยนเป็นสีของอัปเกรดนั้น ใส่ตัวที่สูงกว่าจะได้ตัวเก่าคืน ส่วนตอนทุบลิ้นชัก อัปเกรดจะหล่นออกมาด้วย

### วิธีใช้ลิ้นชัก

| ทำอะไร | ผล |
|---|---|
| ถือของแล้วแตะ | ใส่ของที่ถือ 1 สแต็ก |
| แตะ 2 ทีติดกัน | ใส่ของชนิดนั้นทั้งหมดในกระเป๋า |
| แตะด้วยมือเปล่า | หยิบออก 1 สแต็ก |
| แตะมือเปล่า 2 ทีติดกัน | หยิบออกจนกระเป๋าเต็ม |
| ย่อแล้วแตะ | หยิบออก 1 ชิ้น |
| มองลิ้นชัก | ข้อความบนจอบอกว่าข้างในมีอะไร จำนวนเท่าไหร่ และเก็บได้สูงสุดเท่าไหร่ |

- ลิ้นชัก 2 หรือ 4 ช่อง: ตำแหน่งที่แตะบนหน้าลิ้นชักคือช่องที่เลือก ถ้าแตะด้านอื่น ระบบจะหาช่องที่มีของชนิดเดียวกันหรือช่องว่างให้เอง
- เก็บได้เฉพาะของที่ **ซ้อนได้** และ **ไม่มีเอนชานต์ ชื่อ หรือรอยเสียหาย** ของแบบนี้จะไม่ถูกรับ จึงไม่มีทางหาย
- **ทุบลิ้นชัก:** ถ้าข้างในมีของไม่เกิน 64 สแต็ก ของจะหล่นออกมาทั้งหมด ถ้ามีมากกว่านั้นจะทุบไม่ได้ (กันเกมแล็กจากของหล่นเป็นพันกอง) ให้แตะมือเปล่า 2 ทีเพื่อเอาของออกก่อน
- ลิ้นชักทนระเบิด

## โครงสร้างไฟล์

```
packs/StoragePlus_BP/   Behavior pack (entity, item, block, สูตรคราฟต์, scripts/main.js)
packs/StoragePlus_RP/   Resource pack (texture, model, ภาษาไทย/อังกฤษ)
tools/generate.py       สร้าง JSON และ texture ทั้งหมด (แก้ตัวเลขหรือสีที่นี่)
tools/build.py          generate แล้ว zip เป็น dist/*.mcaddon และ *.mcpack
```

ถ้าจะเปลี่ยนจำนวนหน้าของหีบหรือความจุลิ้นชัก ต้องแก้ทั้งใน `tools/generate.py` และส่วน config บนสุดของ `scripts/main.js` แล้วรัน `python3 tools/build.py`

## หลักการทำงาน (สำหรับคนที่อยากแก้ต่อ)

- **หีบ** คือ entity ที่มี inventory 27 ช่อง ซึ่งเป็นหน้าที่กำลังแสดงอยู่ หน้าอื่น ๆ เก็บไว้ใน entity ล่องหน (`sp:chest_vault`) ที่ตำแหน่งเดียวกัน การเปลี่ยนหน้าใช้ `Container.swapItems` ย้ายของไปมา ข้อมูลของแต่ละชิ้นจึงอยู่ครบ วิธีนี้ใช้หน้าต่างหีบปกติของเกม จึงใช้บนมือถือได้โดยไม่ต้องแก้ UI
- **ลิ้นชัก** คือบล็อก ส่วนข้อมูลข้างใน (ชนิดของ จำนวน และระดับอัปเกรด) เก็บใน world dynamic property ตามพิกัดของบล็อก

## ข้อจำกัดที่รู้อยู่แล้ว

- อย่าใช้ลูกสูบดันลิ้นชัก เพราะข้อมูลผูกกับพิกัด ถ้าโดนดัน ลิ้นชักที่ย้ายไปจะว่างเปล่า
- ฮอปเปอร์ดูดหรือใส่ของในหีบและลิ้นชักไม่ได้
- หีบไม่มีอนิเมชันเปิดฝา
